# Queue item files
One file per item of `docs/QUEUE.md` (tracker), plus `DONE.md`, `LOOP.md`, `WAITING-ON-OWNER.md`, `NEXT-AND-ACTIVE.md`, `HOW-TO-USE.md`, `GAMES-REWRITE.md`.
Naming: `<ID>-<name>.md` (`U3-bridge-builder.md`, `G-01-ball-sort.md`).
Read an item file only when working on that item; dated detail goes in `docs/QUEUE-LOG.md`.
