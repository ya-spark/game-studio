# Issue drafts (not posted)

Drafts for the five new apps and the shared work behind them. Nothing here is posted unless the issue list below says so. Posting a `[new-game]` or `[change]` issue in `ya-spark/game-studio`
starts an automatic run (see `docs/INBOX.md`), so the owner approves each one first. Read `docs/PLAN-new-apps.md` and `docs/DECISIONS.md` before any of them (the "later decisions" parts win where texts differ).

Order: 01a (posted #90, done), 01b (posted #91), 01c, 01d, then the design phase (a live session in Figma, not an issue), then 02, then M1 to M3 (shared minigames),
then 09 (content repo; the owner creates the empty repo first), then 03 to 07 (the five apps) together, then the C issues (content, in `game-content`), then 08.
