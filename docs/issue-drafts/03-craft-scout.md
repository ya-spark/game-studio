# [new-game] Craft Scout Games (Foundation to Year 6)

**Repo:** ya-spark/game-craft-lowteen   **Package:** com.activemindcraft.craftscout   **Audience:** Foundation to Year 6, about 5-12; child-directed

## Goal
Generate the app from the template with the shared engine, then build the launch minigames and starter content.

## Scope
- Two interface levels (about 5-8 and 9-12). Younger level: pictures and voice, no timers. Older level: text and gentle timers.
- Game mode (default) and Study mode with a top-bar toggle and optional parent lock.
- Minigames: door runner, balloon pop, memory match, sort into bins, series builder, word builder.
- Starter content: maths and English from Foundation to Year 6, a few hundred items, original, Australian spelling, the curriculum never mentioned.
- Ads and purchases: child-safe network, banner (menu only) and rewarded only, no interstitials; Remove Ads and coin packs behind the parent gate; no Play Games sign-in
- Never commit secrets. Test ad IDs only until the owner supplies real IDs. Assets listed in `assets/LICENSES.md`.
- `docs/SPEC.md` in the repo is the source of truth for behaviour; write it in the first commit.

## Needs from the owner
AdMob app and ad unit IDs, Play Console setup, spec approval, official name checks.
