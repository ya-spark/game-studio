# Game art prompts (sprite sheets)

How the studio makes art for the games: one AI-generated sprite sheet per game, cut into transparent PNGs, wired in code.
Started 2026-11-21 with Balloon pop (the reference). Pick up the next game from the status table in the app's file.

## Workflow (one game at a time)
1. Take the next `TODO` game in the app's file (`craft-ranger.md` first). Copy its prompt (shared style block + game rows).
2. Owner generates the sheet in Figma's AI image tool (or similar) and exports **PNG, full size (4096x2304), white background kept**.
3. Save the PNG in `sheets/<app>_<game id>.png` and tell Claude the path.
4. Claude: `dart run tools/find_pieces.dart <sheet>` lists piece boxes, writes `tools/<game id>_boxes.json`
   (name to `[x0,y0,x1,y1]`), then `dart run tools/cut_sheet.dart <sheet> <out dir> <boxes.json>` (run from `tools/` after
   `dart pub get`; needs the `image` package, see `tools/pubspec.yaml`) makes transparent PNGs. Check each cut by eye.
5. Copy only the pieces the game uses to the app's `assets/games/<game id>/`, add each to `assets/LICENSES.md` and
   `pubspec.yaml`, change the game screen to use them (text stays drawn in code), run analyze, format, tests, `check_asset_licenses.sh`.
6. Set the game's row to DONE here, with the pieces used and the commit.

## Rules for every prompt
- No people, no faces of people, no text, letters or numbers in the art (the game draws all text). Animals or blobs are fine.
- Flat white background, wide gaps, one grid, so pieces cut cleanly. Landscape 16:9, 4096x2304.
- Same look in every game: the style block below, copied unchanged, so the whole app family matches.
- Blank plates and cards (empty centre) wherever the game puts text on them.
- Only use what the game needs; unused pieces stay in `sheets/`, not in the app.
- Licence line for assets: generated by the owner with Figma's AI image tool, cut by Claude (owner to confirm the wording).

## Shared style block (paste at the top of every prompt)
```
Flat, friendly vector cartoon style for a kids' mobile game (ages 8-13). Thick, even dark-navy outlines (#2D2A4A),
bright saturated fills, one small soft white highlight per shape, light from the top left, no gradients that leave the shape,
no shadows on the background, no text, no letters, no numbers, no people, no watermark. Everything sits on a perfectly
flat plain white background (#FFFFFF) in a clean grid with wide empty gaps (at least 10% of item size) between all items so
each can be cut out. Landscape 16:9 canvas, 4096x2304. All items are original artwork, not based on any existing
character or brand.
```

## Apps
